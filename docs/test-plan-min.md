# test-plan-min: the e2e tests we keep, transform or delete

Task e2e-cull (Gabriel: « Clairement les tests e2e ça nous ralenti énormement … Commençons par supprimer les tests a supprimer et a transformer, et noter ce qui devrait etre ajouté ailleurs »).

Classes:

- **KEEP**: a real path across processes that no unit or integration test can see (hub↔REPL↔TUI, app↔core↔hub, install/update/release, signing, a real socket or PTY, the window server). When unsure: KEEP, with a note.
- **TRANSFORM**: what it asserts can be checked without launching the app, the hub or tmux. The test is deleted; its line in [Transform lines](#transform-lines) says what it guarded, the cheapest place to check it and the fixture. min-tests writes them.
- **DELETE**: it duplicates another test or a law, or checks nothing that matters. "visual only" = a designer sign-off shot or a one-pixel fix with no logic: `tests/harness/showme` and the post-land shots see those.

A deleted file is read with `git show 6f9114127:<path>` (the tree before the cull).
