bise is public today1. one thread per repo: you say what you want, agents work on it in parallel, and you are only interrupted when a decision needs you.

what's in this first release:

  • agents that ask each other before they ask you
  • pages: long answers you can annotate, then send back
  • a voice capsule: hold fn, talk, let go

install it with one line: curl -fsSL https://bise.dev/install | sh, then type show me what you can do.
